Obsidian设置

说明​

[!note] 下面仅列举值得关注的设置项;
重要的设置、值用特殊样式显示, 否则指默认值

极简配置

app.json
{
  "defaultViewMode": "preview",
  "livePreview": false,
  "readableLineLength": false,
  "strictLineBreaks": true,
  "useTab": false,
  "newFileLocation": "current",
  "attachmentFolderPath": "./",
  "newLinkFormat": "relative",
  "alwaysUpdateLinks": true,
  "useMarkdownLinks": true,
  "promptDelete": false,
  "trashOption": "local",
  "showInlineTitle": false
}
appearance.json
{
  "interfaceFontFamily": "Monaco",
  "textFontFamily": "Monaco",
  "monospaceFontFamily": "Monaco",
  "baseFontSize": 18,
  "showViewHeader": true,
  "showRibbon": false,
  "enabledCssSnippets": []
}

关于 About​

  • 自动更新: 否
  • 语言: 简中
  • 应用启动缓慢时进行通知: 是

编辑器 Editor​

  • 默认视图(source/preview): 阅读视图
  • 默认编辑模式(livePreview): 源码模式
  • 缩减栏宽: 是
  • 严格换行: 是
  • 笔记属性: 显示
  • 显示行号: 否
  • 使用制表符: 否
  • 制表符宽度: 4
  • Vim 模式: 否

文件与链接 File & Link​

  • 默认打开文件
  • 新建笔记的存放位置: 当前文件所在的文件夹
  • 附件默认存放路径: 当前文件所在的文件夹
  • 内部链接类型: 相对路径
  • 始终(自动)更新内部链接: 是
  • 使用 Wiki 链接: 否
  • 检测所有类型文件: 是
  • 确认删除: 否
  • 删除文件时删除附件: 每次询问
  • 删除文件位置: .trash
  • 忽略文件
  • 切换配置文件夹

外观 Appearance​

  • 基础颜色: 跟随系统
  • 主题色: #8A5CF5
  • 主题: 默认
  • 字体
    • 界面字体: Monaco
    • 正文字体: Monaco
    • 代码字体: Monaco
    • 字体大小: 18
    • 快速调整字体大小
  • 显示页内标题: 否
  • 显示标签页标题栏: 否
  • 显示功能区: 否
  • 缩放比例: 100%
  • 原生菜单: 是
  • 窗口边框样式: 默认
  • 半透明效果: 否
  • CSS 代码片段

快捷键 Hotkeys​

[!caution] 尽量不要同时包含 cmd 和 ctrl! 因为 cmd 在 Windows 下会被映射为 ctrl!

  • 与上一行互换 | alt+up
  • 与下一行互换 | alt+down
  • 返回 | cmd+[
  • 前进 | cmd+]
  • 切换源码模式 | cmd+alt+e
  • 管理工作区
  • 显示/隐藏功能区
  • 创建时间戳笔记
  • 打开/创建日记
  • 插入脚注
