Office-Word

一、内容元素​

元素本质关键属性
正文主体叙述首行缩进 2 字符，行距 1.5 倍或固定 28–30 磅
标题结构节点核心属性是大纲级别（1–9），而非加粗字号
列表带编号的段落项目符号 / 编号 / 多级；每个列表项 = 一个 ¶
表格二维数据环绕方式（嵌入/环绕）、重复标题行、单元格边距
图表可视化对象环绕方式、题注（SEQ 域）、交叉引用（REF 域）
题注自动编号标签图 1 表 2 —— 本质是 SEQ 域
目录结构导航页TOC 域 扫描大纲级别 1–N 自动生成
页眉/页脚页边缘元信息属于节属性；可设首页不同、奇偶不同
页码页序标记PAGE 域；格式与起始编号在节级别控制
分隔符排版控制符分页符 / 分节符 / 分栏符 / 软回车（Shift+Enter）
脚注/尾注补充说明脚注在页底，尾注在文末；编号可每节或全文连续
公式数学表达式OMML 对象；可套题注

二、四大底层机制​

¶ 段落标记 —— 格式信息容器​

  • 存储：缩进、行距、对齐、大纲级别、编号、边框、制表位
  • 复制文字时带上 ¶ = 复制格式基因
  • 硬回车（Enter）= 新段落；软回车（Shift+Enter）= 同段落换行

§ 节 —— 页面格式边界​

  • 节级属性（不可对单段设置）：纸张大小/方向、页边距、页眉页脚、页码格式、分栏、行号
  • 分节符类型：下一页 / 连续 / 偶数页 / 奇数页
  • 关键开关：页眉页脚工具栏「链接到前一节」—— 取消后本节独立

样式 —— 格式封装​

样式类型作用对象
段落样式整段（标题 1、正文、题注）
字符样式段内部分文字（强调、引用）
链接样式段落+字符混合
表格样式整张表格
列表样式多级列表整体定义

核心原则：内容通过样式定义外观，不直接改格式。

域 —— 动态计算引擎​

域显示内容应用场景
PAGE当前页码页脚
NUMPAGES总页数"共 X 页"
TOC目录自动目录
SEQ序列号题注（图 1、表 2）
REF引用目标交叉引用
STYLEREF样式文本页眉显示当前章标题
DATE当前日期落款

操作：Alt+F9 切换代码/结果；F9 更新域；Ctrl+A → F9 更新全文。

三、三条核心联动链​

链 ①：标题体系​

标题样式（标题 1/2/3）→ 赋予大纲级别 → 导航窗格识别 → TOC 域提取 → 生成目录

► 断点：标题没进目录 → 无大纲级别（用了直接格式而非样式）

链 ②：图表编号体系​

插入图表 → 添加题注（SEQ 域）→ 正文交叉引用（REF 域）→ 增删后 Ctrl+A → F9 同步

► 断点："错误！未找到引用源" → 题注被删或书签断裂

链 ③：页码体系​

封面（§1，无页码）→ 分节符 → 目录（§2，罗马数字 i, ii）→ 分节符 → 正文（§3，阿拉伯数字 1, 2）

► 操作：每节进入页眉页脚 → 取消「链接到前一节」→ 独立设置页码格式与起始编号

清除字符格式Ctrl+空格

格式刷Ctrl+Shift+C / Ctrl+Shift+V
软回车Shift+Enter
分页符Ctrl+Enter
上标Ctrl+Shift+=
下标Ctrl+=

显示域代码Alt+F9
样式窗格Alt+Ctrl+Shift+S

问题排查路径​

  1. 字符层 → Ctrl+空格 清直接格式
  2. 段落层 → 显示 ¶，检查段落标记
  3. 样式层 → 检查样式定义是否被改
  4. 节层 → 检查分节符位置与「链接到前一节」状态
  5. 域层 → Ctrl+A → F9 更新全部域

标准工作流​

页面设置 → 建样式体系 → 配多级列表 → 输内容 → 插图表+题注 → 交叉引用 → 分节 → 设页眉页脚页码 → 插目录 → Ctrl+A → F9 更新
