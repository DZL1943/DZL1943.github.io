Office-Excel

一、层级模型​

工作簿 (Workbook) .xlsx
    └── 工作表 (Worksheet)
            └── 单元格 (Cell) —— 最小数据单元
            └── 区域 (Range) —— 单元格的集合
            └── 表格 (Table) —— 结构化区域

关键认知：Excel 中几乎所有操作最终都落位到单元格或区域上。理解单元格的寻址、引用和计算机制，是掌握 Excel 的核心。

二、单元格：核心操作对象​

2.1 地址系统​

引用形式写法示例
A1 样式列字母 + 行数字A1、B2、AA100
R1C1 样式R行C列R1C1（=A1）、R[1]C[-1]（相对引用）
跨表引用表名!地址Sheet2!A1、'1月'!B3（表名含空格需加单引号）
跨簿引用[簿名]表名!地址[数据.xlsx]Sheet1!$A$1

2.2 数据类型​

Excel 单元格存储的不是"文字"，而是带类型的数据：

类型特征注意
文本左对齐；公式中需用引号 ""数字前加单引号 '001 强制转文本
数值右对齐；参与算术运算超过 15 位有效数字会精度丢失（身份证号需设文本）
日期/时间本质是序列号（1900-1-1 = 1）日期是整数，时间是小数；可直接加减
布尔值TRUE = 1，FALSE = 0可直接参与计算：=TRUE+1 → 2
错误值#VALUE! #REF! 等具有传染性，需用错误处理函数隔离

2.3 格式 vs. 内容​

核心区分：单元格看到的 ≠ 单元格存储的。

  • 格式（Format）：决定显示样子，不改变底层值
    • 例：单元格值是 0.75，格式设为百分比 → 显示 75%，但值仍是 0.75
    • 例：格式设为 "第"0"名" → 输入 3 显示 第3名
  • 内容（Value）：单元格实际存储的数据

陷阱：SUM 等函数读取的是底层值，不是显示值。文本型数字不参与求和。

2.4 引用类型​

这是公式系统的基石。

类型写法拖动/复制时的行为
相对引用A1行列均随位置偏移
绝对引用$A$1行列均锁定，不偏移
混合引用$A1 或 A$1锁定列/行中的一个，另一个偏移

切换快捷键：F4 循环切换 A1 → $A$1 → A$1 → $A1 → A1

应用场景：

  • 相对：同列公式下拉，如 =A1+B1 下拉变 =A2+B2
  • 绝对：引用固定参数表，如 =A1*$E$1（汇率/税率固定）
  • 混合：二维查找矩阵，如 =VLOOKUP(A2,$E$1:$G$10,2,0) 中锁定查找区域

2.5 名称管理器（Name Manager）​

给区域或公式起别名，替代复杂引用。

  • 定义：公式 → 定义名称，如将 B2:B100 命名为「销售额」
  • 使用：=SUM(销售额) 替代 =SUM(B2:B100)
  • 命名规则：不能以数字开头，不能含空格（可用下划线），不能与单元格地址冲突

三、公式系统​

3.1 公式的本质​

公式是以 = 开头的计算表达式，返回一个值到单元格。其内部可以包含：

  • 常量：100、"文本"、TRUE
  • 引用：A1、$B$2、Table1[销售额]
  • 运算符：+ - * / ^ % & = > < >= <= <>
  • 函数：SUM()、IF()、VLOOKUP() 等

3.2 运算符优先级​

:（区域）> ,（联合）> 空格（交叉）    ← 引用运算符
-（负号）
%（百分比）
^（乘方）
* /（乘除）
+ -（加减）
&（文本连接）
= > < >= <= <>（比较）

括号 () 可强制改变优先级。

3.3 函数分类速查​

类别代表函数用途
数学统计SUM AVERAGE MAX MIN COUNT COUNTA SUMIF SUMIFS COUNTIF COUNTIFS聚合计算、条件求和计数
逻辑判断IF AND OR NOT IFS SWITCH条件分支
查找引用VLOOKUP HLOOKUP INDEX MATCH XLOOKUP OFFSET INDIRECT跨表/跨区域取值
文本处理LEFT RIGHT MID LEN FIND SUBSTITUTE TEXT CONCAT TEXTJOIN字符串截取、拼接、格式化
日期时间TODAY NOW DATE YEAR MONTH DAY DATEDIF EOMONTH WORKDAY日期计算、工作日推算
财务PV FV PMT NPV IRR现值、终值、年金、收益率
信息判断ISBLANK ISNUMBER ISTEXT ISERROR IFERROR类型检查、错误隔离
动态数组FILTER SORT UNIQUE SEQUENCE XLOOKUP LETExcel 365 新函数，返回溢出数组

3.4 核心函数组合模式​

① 安全查找：INDEX + MATCH

=INDEX(返回列, MATCH(查找值, 查找列, 0))
  • 比 VLOOKUP 灵活：可左向查找，不受插入列影响
  • 第三个参数 0 表示精确匹配

② 条件聚合：SUMIFS / COUNTIFS

=SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2)
  • 条件可用通配符：* 代表任意多个字符，? 代表单个字符
  • 条件为文本或比较式时需加引号：">60" "*北京*"

③ 错误隔离：IFERROR

=IFERROR(原公式, 出错时显示值)
  • 例：=IFERROR(VLOOKUP(...), "未找到")

④ 文本日期转标准日期

=--SUBSTITUTE(A1,".","-")    ' 2024.07.18 → 2024-07-18（日期序列号）
=DATE(MID(A1,1,4),MID(A1,6,2),MID(A1,9,2))  ' 从文本提取年月日

3.5 数组公式与动态数组​

传统数组公式（Ctrl+Shift+Enter）：

  • 对一组值执行运算，返回一组结果
  • 公式两端出现花括号 {}，表示数组公式

动态数组（Excel 365 / 2021+）：

  • 公式自动返回一个溢出区域（Spill Range），无需三键
  • 溢出区域下方不能有数据，否则报 #SPILL!
动态数组函数作用
FILTER按条件筛选区域
SORT / SORTBY排序
UNIQUE去重
SEQUENCE生成数字序列
XLOOKUP新一代查找，替代 VLOOKUP+INDEX/MATCH
LET定义变量，简化复杂公式

3.6 常见错误值​

错误值含义常见原因
#VALUE!值错误公式中用了错误的数据类型
#REF!引用错误引用的单元格/区域被删除
#NAME?名称错误函数名拼写错误，或自定义名称不存在
#DIV/0!除零错误除数为 0 或空单元格
#N/A找不到查找函数未匹配到值
#NUM!数字错误数值超出范围或迭代不收敛
#NULL!交集错误区域间无交集（如 =SUM(A1:B2 C3:D4)）
#SPILL!溢出错误动态数组结果区域被占用

四、数据工具​

4.1 数据验证（Data Validation）​

限制单元格可输入的内容，从源头控制数据质量。

验证类型示例
整数/小数只能输入 0–100 的整数
序列下拉列表选择（来源：男,女 或引用区域）
日期只能输入 2024-1-1 到 2024-12-31 的日期
文本长度身份证号必须 18 位
自定义用公式判断，如 =COUNTIF($A$1:$A$100,A1)=1（防重复）

4.2 条件格式（Conditional Formatting）​

根据单元格值自动改变显示格式，本质是格式规则而非改值。

规则类型用途
突出显示单元格大于/小于/等于/包含某值
最前/最后规则前 10 项、高于平均值
数据条/色阶/图标集可视化大小关系
使用公式确定如 =A1>B1 则标红；行内隔行填色 =MOD(ROW(),2)=0

4.3 数据透视表（PivotTable）​

对大规模数据进行快速汇总与多维分析的工具。

概念：

  • 行字段：分类维度（如部门、产品）
  • 列字段：交叉维度（如月份、地区）
  • 值字段：聚合计算（求和、计数、平均）
  • 筛选字段：全局过滤条件

本质：不修改源数据，生成一个动态汇总视图。源数据更新后需刷新（右键 → 刷新 或 Alt+F5）。

问题排查路径​

  1. 显示问题 → 检查单元格格式（尤其是日期/数字显示为 ##### 是列宽不够）
  2. 计算问题 → 检查公式是否以 = 开头；检查引用类型（相对/绝对）
  3. 类型问题 → 文本型数字不参与计算；用 ISTEXT/ISNUMBER 检查
  4. 错误传播 → 追溯错误源头，用 IFERROR 隔离
  5. 性能问题 → 避免整列引用（如 A:A），尽量限定区域；减少 VOLATILE 函数（NOW、RAND、INDIRECT、OFFSET）的过度使用

标准工作流​

规划表结构（字段设计、数据类型）
    → 输入/导入数据
    → 设置数据验证（防脏数据）
    → 写公式计算
    → 条件格式高亮关键信息
    → 数据透视表汇总分析
    → 图表可视化
    → 保护/分享
