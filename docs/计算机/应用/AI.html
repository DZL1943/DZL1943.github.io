AI

一、概念​

  • LLM：大模型，负责处理信息
  • Agent：负责本地执行和与 LLM 交互
  • RAG：一种专用于知识库的 Agent
  • MCP：扩展 Agent 的内置操作能力
  • Skill：本质是供 Agent 查阅的文档或脚本

可选读背景：ML → DL → Transformer → Prompt Engineering → 原生多模态 → MoE

三、进阶​

模型部署​

  • Ollama — 一行命令本地运行开源模型
  • LM Studio — 可视化桌面客户端
  • vLLM — 高吞吐生产级推理引擎
  • SGLang — 长上下文友好推理
  • Xinference — 国产开源推理平台
  • llama.cpp — C++ 端侧部署首选
  • TGI — Hugging Face 生产级推理

工作流编排​

  • LangChain — 链、记忆、工具调用通用框架
  • LlamaIndex — 专注 RAG 的数据连接与索引
  • CrewAI — 多智能体角色协作
  • MetaGPT — 多智能体模拟软件公司
  • n8n — 开源低代码工作流编排
  • Dify — 开源 LLMOps 平台
  • Coze — 低代码聊天机器人，抖音/飞书生态
  • Flowise — 拖拽式 LLM 流程构建器
  • LangFlow — 可视化 LangChain 流程

RAG 搭建​

  • AnythingLLM — 开源全栈私有化 ChatGPT
  • FastGPT — 开源知识库问答系统
  • Haystack — 端到端搜索系统框架
  • Ragas — RAG 系统评估框架

Agent 开发​

  • Exa MCP — 语义搜索，AI 优化检索

  • Supabase MCP — 官方，Postgres + auth + storage
  • PostgreSQL MCP — SQL 查询、Schema 探索

  • ClaudeSkills.info — 最大免费 Skill 目录，GitHub 聚合

  • Anthropic 官方 Skills — Claude Code 内置示例 Skill 仓库
