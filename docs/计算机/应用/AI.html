AI

一、概念​

  • LLM：大语言模型，负责理解与生成信息，是 Agent 的认知基础。
  • Agent：智能体，负责任务拆解、工具调用与本地执行，并与 LLM 持续交互。
  • RAG：检索增强生成，为 LLM 补充外部知识，常用于知识库问答，缓解幻觉。
  • MCP：模型上下文协议，统一 Agent 与外部工具、数据源的通信标准，相当于 AI 的「USB 接口」。
  • Skill：技能，本质是供 Agent 查阅的文档或脚本，决定其在特定领域的做事方法。
  • Harness：执行框架，管理上下文压缩、权限边界、重试策略与安全沙箱，决定能力能否稳定闭环。

可选读背景：ML → DL → Transformer → Prompt Engineering → 原生多模态 → MoE
