rsync

重要选项​

  • -a (archive)
    归档模式，相当于 -rlptgoD。递归、保留符号链接、权限、时间戳、属组、属主，并保留设备文件与特殊文件。常用于备份。

  • -n (dry-run)
    模拟运行，只显示将要执行的操作，不实际传输文件。建议任何高危操作前先用 -n 检查。

  • --no-links
    忽略符号链接。当 -a 默认包含 -l（复制符号链接本身）时，添加该选项会跳过所有符号链接（既不复制链接，也不复制其指向的文件）。如需把链接替换为实际文件，请用 -L (--copy-links)。

  • --delete
    删除目标端有而源端没有的文件，使目标目录与源完全一致。务必先使用 -n 模拟运行。
    可配合 --delete-excluded 等参数进一步清理。

  • --exclude
    排除匹配模式的文件或目录。例如 --exclude='*.tmp' 或 --exclude='.git/'。支持多次使用。

  • -P
    等价于 --partial --progress。显示每个文件的传输进度，并保留未完成传输的文件，方便断点续传。

辅助选项​

  • -v (verbose)
    详细输出，列出正在传输的文件。使用 -vv 可获取更详细的信息。

  • -h (human-readable)
    以人类易读格式显示数字（如 1K、234M、2G）。

其他常用选项（补充）​

  • -z (compress)：传输时压缩数据，适合较慢网络。
  • -e：指定远程 shell，如 -e "ssh -p 2222"。
  • --progress：显示文件传输进度（已包含在 -P 中）。
  • --partial：保留部分传输的文件，断点续传（已包含在 -P 中）。
  • --bwlimit=RATE：限制传输带宽，单位 KB/s，如 --bwlimit=1000。
  • --delete-excluded：同时删除目标端被排除的文件。
  • -L (--copy-links)：将符号链接替换为它们指向的实际文件/目录。
  • -r (recursive)：递归目录（-a 已包含）。

注意​

  1. 源路径尾斜杠的陷阱

    • source/：复制该目录下的内容，不包含目录名本身。
    • source：复制整个目录（包含目录名）。
      示例：rsync -a source ~/bak 会生成 ~/bak/source/...；而 rsync -a source/ ~/bak 会将 source 内的文件和子目录直接放入 ~/bak/。

  2. 目标路径尾斜杠通常无影响，但为了清晰，建议保持与源路径一致的写法。

  3. --delete 风险：会把目标目录中多余的文件全部删除。务必先用 rsync -avn --delete source/ target/ 预演。

  4. 首次使用务必 -n 测试，确认不会误删或覆盖。

  5. 远程同步时，路径格式为 user@host:/path，需配置好 SSH 免密登录或输入密码。

用例​

# 1. 本地备份：将 source 目录完整备份到 ~/bak 下（保留目录名）
rsync -avh source ~/bak

# 2. 只同步目录内容（不包含顶层目录名）
rsync -avh source/ ~/bak/

# 3. 模拟运行，查看哪些文件会被同步或删除
rsync -avn --delete source/ ~/bak/

# 4. 远程推送（本地 → 远程），压缩传输，显示进度并支持断点续传
rsync -avzP -e ssh /local/dir user@remote:/backup/

# 5. 远程拉取（远程 → 本地）
rsync -avzP -e ssh user@remote:/remote/dir /local/dir

# 6. 同步时排除 .git 和 node_modules，并删除目标多余文件
rsync -av --delete --exclude='.git/' --exclude='node_modules/' source/ ~/bak/

# 7. 限制带宽为 500 KB/s 进行远程备份
rsync -av --bwlimit=500 source/ user@remote:~/backup/

# 8. 将符号链接替换为实际文件进行备份
rsync -avL source/ ~/bak/
