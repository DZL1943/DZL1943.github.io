find

一、核心语法​

find [起始路径...] [匹配条件] [动作]
  • 起始路径默认为当前目录 .
  • 多个条件默认是 与（AND） 关系
  • 动作默认 -print（换行输出路径）

二、按名称与路径查找​

# 精确匹配名称（区分大小写）
find . -name '*.json'

# 忽略大小写
find . -iname '*.png'

# 正则匹配完整路径（GNU find 支持 -regextype 指定类型）
find . -regex '.*/[A-Z]+\.txt'

# 按路径模式匹配（可用于排除目录）
find . -path './node_modules/*' -prune -o -name '*.js' -print

三、目录深度控制​

# 仅查找当前目录（不递归）
find . -maxdepth 1 -type f -printf '%P\n'

# 指定最小深度（跳过前 N 层）
find . -mindepth 2 -name '*.log'

四、按文件类型​

-type 值含义
f普通文件
d目录
l符号链接
b / c块/字符设备
p命名管道
ssocket

五、按大小​

# 大于 100M
find . -size +100M -exec ls -lh {} \;

# 小于 1MB（注意 k 是 1024 字节）
find . -size -1024k

# 精确 0 字节（空文件）
find . -size 0

# 常用单位：c(字节), k(KB), M(MB), G(GB)

六、按时间​

参数含义示例
-mtime +n修改时间 > n 天-mtime +7 7天前修改
-mtime -n修改时间 < n 天-mtime -1 1天内修改
-mmin nn 分钟前修改-mmin -30 最近30分钟
-newer file比 file 新-newer a.txt
-newermt "2026-07-01"修改时间晚于指定日期需要 GNU find
# 查找最近24小时内修改的 .log 文件
find . -name '*.log' -mtime -1

七、排除指定目录​

# 排除多个目录（方法一：多次 -path + -prune）
find . \
  ! \( -path './.trash/*' -o -path './.obsidian/*' \) \
  -name '*.png'

# 方法二：使用 -prune 修剪
find . \
  -path './.trash' -prune -o \
  -path './resources' -prune -o \
  -name '*.png' -exec ls -lh {} \;

# 排除所有 .git / node_modules 类目录
find . \( -name '.git' -o -name 'node_modules' \) -prune -o -type f

注意 ! -path './dir/*' 仅排除目录内容，目录本身仍会出现；-prune 可彻底跳过整个目录。

八、逻辑运算符​

运算符写法说明
与(默认)条件1 条件2
或-o条件1 -o 条件2
非! 或 -not! -name '*.tmp'
分组\( ... \)避免 shell 括号解释，必须转义
# 查找所有 .jpg 或 .png 图片
find . -name '*.jpg' -o -name '*.png'

九、常用动作​

1. 默认打印​

# 换行输出
find . -name '*.conf'

# 使用 \0 分隔（配合 xargs -0 处理空格/换行等特殊文件名）
find . -name '*.conf' -print0 | xargs -0 du -h

2. 执行命令​

# 对每个文件执行一次
find . -name '*.sh' -exec chmod +x {} \;

# 批量传参（用 + 结尾，性能更好）
find . -name '*.jpg' -exec mogrify -resize 800 {} +

# 交互式执行，每次询问
find . -name '*.bak' -ok rm {} \;

3. 格式化输出（GNU find）​

# 仅输出相对路径（类似你的需求）
gfind .obsidian -maxdepth 1 -type f -printf '%P\n'

# %p: 完整路径 %P: 去掉起始路径 %f: 文件名 %s: 字节大小 %T+: 时间
find . -type f -printf '%s\t%p\n' | sort -n

4. 删除​

# 直接删除匹配的文件（谨慎使用）
find . -name '*.swp' -delete

十、实战组合​

# 查找大文件并按大小排序（GNU）
find . -type f -size +100M -printf '%s %p\n' | sort -nr | head

# 查找30分钟内修改过的非空 .log，并列出详细信息
find . -name '*.log' -mmin -30 ! -size 0 -exec ls -lh {} \;

# 批量重命名（将所有 .jpeg 改为 .jpg，需 bash）
find . -name '*.jpeg' -exec bash -c 'mv "$1" "${1%.jpeg}.jpg"' _ {} \;

# 清理 N 天前的临时文件
find /tmp -type f -name '*.tmp' -mtime +3 -delete

提示：

  • 上述大部分示例使用 GNU find（Linux 常见），macOS 自带 BSD find 部分选项（如 -printf、-newermt）不兼容。若在 macOS 上，可通过 brew install findutils 安装 gfind 使用。
  • 操作删除或批量修改时，务必先 -print 确认匹配结果，再用 -delete 或 -exec。
