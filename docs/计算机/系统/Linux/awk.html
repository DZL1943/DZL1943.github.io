awk

一、awk 是什么​

awk 是一个强大的文本处理工具，得名于其三位创始人 Alfred Aho、Peter Weinberger 和 Brian Kernighan 的姓氏首字母。它能逐行扫描文件，按指定模式匹配行，并对匹配到的行执行一系列操作。常用于数据提取、格式化输出、简单统计等。

基本工作流程​

awk 按行读取输入，将每行按分隔符（默认为空白字符）分割成若干个字段，分别记为 $1, $2, $3, ...，整行内容为 $0。然后对匹配模式的行执行动作。

二、基本语法​

awk '模式 { 动作 }' 文件名
  • 模式：可以是正则表达式、条件判断、特殊模式 BEGIN/END。省略模式则对每一行都执行动作。
  • 动作：在大括号中编写要执行的操作，如打印、计算等。如果省略动作，默认动作为 print $0。

常用选项​

  • -F 分隔符：指定输入字段分隔符。
  • -v 变量=值：在 awk 脚本中设置变量。

三、内建变量​

变量含义
$0整行内容
$1, $2, ...第1、第2...个字段
NF当前行的字段数
NR当前处理的行号（累计）
FNR当前文件的行号（多文件时各文件独立计数）
FS输入字段分隔符（默认空白）
OFS输出字段分隔符（默认空格）
RS输入记录分隔符（默认换行）
ORS输出记录分隔符（默认换行）
FILENAME当前处理的文件名

四、常用示例​

1. 打印某列​

# 打印第1列和第3列
awk '{print $1, $3}' file.txt

2. 指定分隔符​

# 使用逗号作为分隔符，打印第2列
awk -F, '{print $2}' file.csv
# 或用 BEGIN 块设置 FS
awk 'BEGIN{FS=","} {print $2}' file.csv

3. 按条件过滤​

# 只打印第3列大于100的行
awk '$3 > 100' file.txt
# 打印包含 "error" 的行
awk '/error/' log.txt
# 第2列等于 "yes" 的行
awk '$2 == "yes"' data.txt

4. 添加开头/结尾内容 (BEGIN/END)​

awk 'BEGIN{print "姓名 成绩"} {print $1, $3} END{print "---结束---"}' file.txt

5. 计算总和与平均值​

# 求第2列之和
awk '{sum += $2} END{print sum}' file.txt
# 求平均值
awk '{sum += $2; count++} END{print sum/count}' file.txt

6. 使用变量​

# 传入外部变量
awk -v threshold=50 '$2 > threshold' file.txt

7. 格式打印 (printf)​

awk '{printf "%-10s %5d\n", $1, $2}' file.txt

8. 多条件与逻辑运算​

# AND: 第1列 > 10 且 第2列 < 20
awk '$1>10 && $2<20' file.txt
# OR: 匹配 "error" 或 "fail"
awk '/error/ || /fail/' log.txt
# NOT: 不匹配注释行
awk '!/^#/' config.txt

9. 范围模式​

# 打印从匹配 "START" 到 "END" 之间的行
awk '/START/,/END/' file.txt

10. 字符串处理​

# 获取字段长度
awk '{print length($1)}' file.txt
# 拼接字符串
awk '{print $1 "-" $2}' file.txt
# 查找子串位置
awk '{print index($0, "abc")}' file.txt
# 提取子串
awk '{print substr($0, 1, 5)}' file.txt

五、脚本形式​

可以将 awk 脚本写入文件，然后通过 -f 调用：

awk -f script.awk input.txt

脚本示例 script.awk：

BEGIN {
    FS=","
    print "ID\tName"
}
NR>1 {
    printf "%d\t%s\n", $1, $2
}
END {
    print "Total lines processed:", NR
}

六、注意事项​

  • 默认以任意空白（空格、制表符）分割字段，若需固定分隔符必须用 -F 或 FS 设置。
  • 数字与字符串比较规则：如果操作符两边都是数字形式则按数值比较，否则按字符串比较。可用 +0 强制转为数值。
  • 在 BEGIN 块中，NR、FNR 等行相关变量未被定义或为 0。
  • 大括号内的语句用分号分隔，动作省略时默认打印整行。
