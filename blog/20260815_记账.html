20260815_记账

2024年8月20日 · 阅读需 3 分钟

引言​

为什么要记账？

  • 梳理资产债务
  • 了解资金流向
  • 规划资金预算

记哪些东西？

  • 时间
  • 摘要
  • 金额
  • 来源
  • 去向

怎么记？

  • 单式记账
  • 复式记账
    • 借贷记账
    • 增减记账
    • 收付记账

用什么工具记？

原理​

收入 - 费用 = 利润
资产 = 负债 + 所有者权益 = 负债 + (期初所有者权益 + 收入 - 费用)

符号约定（增加时）：+ 表示借方（Debit），- 表示贷方（Credit）

  • 收入 Revenues/Income | -
  • 费用 Expenses | +
  • 资产 Assets | +
  • 负债 Liabilities | -
  • 权益 Equity | -

根据净资产的变化可将交易分为如下类别：

  • 支出类
    • 资产↓ > 支出↑
    • 负债↑ > 支出↑
  • 收入类
    • 收入↓ > 资产↑
  • 转账类
    • 资产↓ > 资产↑
    • 借入：负债↑ > 资产↑
    • 还款：资产↓ > 负债↓

实践​

Excel 记账​

  • 每条记录对应一个账户和分类
  • 每条记录两个科目，且固定方向，不记符号，例如固定金额方向始终为来源账户的减少量
    • 科目表
      • 名称 Name
      • 类型 Type: 资产、负债、收入、支出、权益
      • 期初
      • 期末 Balance
    • 交易表
      • 日期 Date
      • 描述 Payee|Description
      • 金额 Amount %% price * quantity %% %% 对应来源账户减少, 去向账户增加 %%
      • 来源账户 From %% 关联到账户表的 Name (可排除支出) %%
      • 去向账户 To %% 关联到账户表的 Name %%
    • 透视表
      • 时间
      • 来源
      • 去向
  • （真正的复式）每笔交易分多条记录，每条一个科目

结合 todo 的简易记账方法​

title: 结合 todo 的简易记账方法
collapse: true
- 日期作为标题
- 按收款方分组, 若分类需要也可进一步划分
- 注意不要重复记录, 比如可以用 `:` 的方式备注金额
- 字段: Payee|Desc 描述, Amount 金额, From 转出账户, To 转入账户/科目
import re
from decimal import Decimal

def markdown_to_hledger(md_content):
    entries = []
    current_date = None
    account_cache = set()

    for line in md_content.split('\n'):
        line = line.strip()
        
        # 解析日期标题
        date_match = re.match(r'^##\s+(\d{4}-\d{2}-\d{2})', line)
        if date_match:
            current_date = date_match.group(1)
            continue
            
        # 解析所有层级的条目
        entry_match = re.match(r'^\s*-\s+\[[ x]\]\s*(.+?)\s*$', line)
        if current_date and entry_match:
            parts = [p.strip() for p in entry_match.group(1).split('|')]
            if len(parts) < 4 or not all(parts[:4]):
                continue  # 跳过不完整条目
                
            name, amount_str, source, dest = parts[:4]
            
            try:
                amount = Decimal(amount_str)
            except:
                continue  # 跳过金额无效条目
                
            # 构建账户名称并缓存
            source_acc = f"Assets:{source}"
            dest_acc = f"Expenses:{dest}"
            account_cache.update([source_acc, dest_acc])
            
            # 生成hledger条目
            entry = [
                f"{current_date} {name}",
                f"    {dest_acc:<24} {amount:.2f} CNY",
                f"    {source_acc}"
            ]
            entries.append('\n'.join(entry))
    
    # 添加账户声明
    accounts = '\n'.join([f"account {acc}" for acc in sorted(account_cache)])
    return f"{accounts}\n\n" + '\n\n'.join(entries)
